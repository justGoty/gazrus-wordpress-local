# Газоанализатор.рус — рабочий репозиторий

## Подготовка полной переработки

Новая версия инженерного B2B-каталога находится в `web/`. WordPress больше не считается обязательной основой: текущая сборка сохраняется как прототип и источник контента. Пакет анализа, дизайн-направлений, SEO, архитектуры и вопросов владельцу находится в [docs/rebuild/README.md](docs/rebuild/README.md).

Подключение коллеги, правила Git и порядок работы другого чат-бота описаны в [COLLEAGUE_ONBOARDING.md](COLLEAGUE_ONBOARDING.md).

Локальная рабочая копия сайта `газоанализатор.рус` / `new.газоанализатор.рус` для доработки дизайна, темы и кастомной логики WordPress.

## Что входит в репозиторий

- `web` — новая версия каталога на Next.js и TypeScript.
- `docker-compose.yml` — локальное окружение WordPress + MariaDB.
- `wp-content/themes/gazrus` — активная кастомная тема сайта.
- `wp-content/plugins/gazrus-core` — кастомный плагин с типами записей, таксономиями, SEO-полями и формой заявки.
- `scripts/enable-wsl-for-docker.ps1` — вспомогательный скрипт для включения WSL/Docker на Windows.
- `WORKLOG.md` — краткая история текущих дизайн-работ.

## Что не публикуется

В публичный GitHub намеренно не добавлены:

- дампы базы данных;
- серверные бэкапы;
- рабочие скриншоты и временные артефакты;
- `wp-content/uploads`;
- `.env` и любые файлы с приватными настройками.

Если на другом ПК нужен не пустой WordPress, а точная копия контента, приватный дамп БД и медиафайлы нужно передать отдельно безопасным способом.

## Запуск новой версии

Требования: Node.js 22 и pnpm 11.9.0.

```powershell
cd web
pnpm install --frozen-lockfile
pnpm dev -p 8090
```

Новая версия: `http://localhost:8090/`.

## Запуск WordPress-прототипа

Требования:

- Docker Desktop;
- включенный WSL 2 на Windows;
- Git.

Команды:

```powershell
git clone <repo-url>
cd gazrus-wordpress-local
docker compose up -d
```

WordPress будет доступен по адресу:

```text
http://localhost:8089
```

Админка:

```text
http://localhost:8089/wp-admin/
```

При первом запуске без приватного дампа WordPress откроет стандартную установку. После установки нужно активировать тему `Gazrus` и плагин `Gazrus Core`.

## Импорт приватной базы

Для полной локальной копии:

1. Получить приватный SQL/SQL.GZ дамп отдельно от публичного репозитория.
2. Положить дамп в локальную папку `db/init`.
3. При необходимости добавить SQL-скрипт замены URL на `http://localhost:8089`.
4. Пересоздать volume базы:

```powershell
docker compose down -v
docker compose up -d
```

Скрипты из `db/init` выполняются только при первом создании Docker volume базы.
