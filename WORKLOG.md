## Продолжение работы

1. Запустить Docker Desktop.
2. Открыть папку проекта.
3. Выполнить:

```powershell
docker compose up -d
```

4. Открыть сайт:

```text
http://localhost:8089
```

5. Продолжить дизайн по очереди:
   - финальная анимация hero-слайдера;
   - подбор/генерация корректных изображений для стационарных приборов, портативных приборов и сенсоров;
   - перенос удачных решений со старого сайта;
   - доработка калькулятора газов;
   - подготовка к переносу на WordPress staging.
