# Активные задачи

Этот файл предотвращает одновременное изменение одних файлов двумя исполнителями при работе напрямую через `master`.

## Правило бронирования

Перед задачей длительностью более 30 минут исполнитель:

1. Выполняет `git pull --ff-only origin master`.
2. Добавляет строку в таблицу: исполнитель, задача, затрагиваемые файлы, базовый хеш и статус `active`.
3. Делает отдельный commit и push бронирования.
4. Только после подтверждения remote hash начинает менять заявленные файлы.
5. В финальном коммите удаляет строку или переводит ее в `completed`, обновляет `WORKLOG.md` и выполняет push.

Если нужный файл уже занят, исполнитель выбирает непересекающуюся работу или ждет завершения задачи.
