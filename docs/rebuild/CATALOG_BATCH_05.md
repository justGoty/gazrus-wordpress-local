## Подтвержденные ограничения и вариативные поля

- ДАК — семейство исполнений. Определяемый компонент, поверочный компонент, диапазон, питание, выходы, материал корпуса и температурный класс фиксируются в точном обозначении.
- Для ДАК степень IP66/IP68 относится к оболочке с подходящими кабельными вводами и заглушками; универсальная комплектация кабельного ввода не заявляется.
- МАГ-6 С-П контролирует один компонент. Восемь газов в карточке — это доступные исполнения, а не одновременное измерение.
- Руководство МАГ-6 С-П указывает питание 5–24 В, официальная страница серии — 12–24 В, а фильтр каталога — 6–24 В. В карточке приведено значение из РЭ и оставлено требование подтвердить питание конкретной поставки.
- Диапазон и погрешность МАГ-6 С-П зависят от газового исполнения; универсальный диапазон не опубликован.
- Polytron 8100 EC измеряет один газ с одним выбранным DrägerSensor. Диапазон и рабочие характеристики определяются таблицей данных сенсора.
- Для Polytron 8100 EC цифровой интерфейс, релейный модуль, корпус, кабельный ввод и выносная сенсорная головка выбираются в конфигурации.
- Российская поверка, российские сертификаты, цена, наличие и срок поставки для этих трех позиций не заявлены.
- Официальный CDN Dräger блокировал прямую загрузку изображения в рабочем окружении. Для обработки получена копия файла с тем же заводским именем `D-2948-2018`; визуальное соответствие официальной карточке подтверждается, но побайтовое совпадение с CDN изготовителя проверить не удалось.
