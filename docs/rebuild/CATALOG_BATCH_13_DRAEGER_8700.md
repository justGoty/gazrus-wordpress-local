## Разделение исполнений

### PIR 7000 Type 334

- Базовая заводская настройка: метан, 0–100 % НКПР.
- Возможные настройки: метан, пропан, этилен.
- Руководство отдельного PIR 7000 приводит для метана верхний предел 15…2000 % НКПР либо 1…100 % об., для пропана — 20…100 % НКПР, для этилена — 25…100 % НКПР.

### PIR 7000 Type 340

- Базовая заводская настройка: пропан, 0–100 % НКПР.
- Возможные настройки: пропан и метан.
- Руководство отдельного PIR 7000 приводит для пропана верхний предел 5…100 % НКПР либо 850…21000 ppm, для метана — 15…100 % НКПР.

Product Information комплектного Polytron 8700 указывает более консервативный системный диапазон для метана, пропана и этилена 0–20…100 % НКПР и отдельный диапазон метана 0–100 % об. Поэтому расширенные пределы из руководства PIR 7000 не перенесены в структурированные диапазоны карточки автоматически. Типы 334 и 340 используют разные рабочие длины волн и не представлены как взаимозаменяемые без проверки газа, диапазона, калибровки и заказного кода.

## Интерфейсы и реле

- Аналоговое исполнение: 4–20 мА с HART, 3- или 4-проводное подключение, sink или source.
- Цифровые исполнения: Modbus RTU, PROFIBUS PA либо FOUNDATION Fieldbus H1.
- Эти интерфейсы не описаны как один одновременно доступный универсальный комплект: вариант выбирается при конфигурировании.
- Для соответствующих исполнений 4–20 мА / HART доступны опциональные 2 реле тревоги и 1 реле неисправности.

## Ex, IP и температура

- Оболочки: взрывонепроницаемая `d` либо комбинированная `d/e` с док-станцией.
- IECEx для 4–20 мА / HART: `Ex db IIC T6/T4 Gb` или `Ex db eb IIC T6/T4 Gb`; пылевая защита `Ex tb IIIC T80/130 °C Db`.
- ATEX для 4–20 мА / HART: `II 2G Ex db IIC T6/T4 Gb` или `II 2G Ex db eb IIC T6/T4 Gb`; `II 2D Ex tb IIIC T135 °C Db`.
- Для PROFIBUS PA и FOUNDATION Fieldbus маркировка включает `ia`; точная строка зависит от оболочки.
- Степень защиты: IP65 / IP66 / IP67, также заявлены NEMA 4X и 7.
- Европейская Product Information 101867 указывает рабочую температуру −40…+65 °C.
- Североамериканская Product Information 9107420 указывает −40…+77 °C без реле и −40…+70 °C с реле.
- В карточке нет единого завышенного предела: покупателю предлагается сверять исполнение, сенсор и применимый сертификат.

## Точность формулировок

- Для базовой конфигурации Product Information заявляет чувствительность/повторяемость не хуже ±1 % НКПР.
- Долговременный дрейф: до ±1 % НКПР за 12 месяцев.
- T90: 4 с без брызгозащитного кожуха.
- Эти значения не распространены автоматически на каждый газ, диапазон и режим PIR 7000; соответствующее ограничение внесено в карточку.
