## Разделение исполнений и диапазонов

MONOLIT S содержит от одного до двух измерительных каналов. Карточка не представляет O₂, CO₂ и ΣCH как обязательный одновременный набор.

- O₂: отдельные исполнения 0–25 % об. и 0–100 % об.; для диапазона 0–100 % об. погрешность нормируется по участкам 0–10 и 10–100 % об.
- CO₂: отдельные исполнения 0–5 % об. и 0–100 % об.; погрешность нормируется по участкам 0–0,5 / 0,5–5 и 0–10 / 10–100 % об. соответственно.
- ΣCH: отдельные исполнения 0–5 % об. и 0–100 % об.; конкретный углеводород или пары нефтепродуктов для градуировки выбираются при заказе.

Полный перечень компонентов градуировки канала ΣCH приведён в официальном руководстве и описании типа. В карточке не создаются отдельные неподтверждённые товарные модификации для каждого вещества.

## Подтверждённые параметры

- один или два канала в зависимости от исполнения;
- электрохимический датчик для O₂ и оптический датчик для CO₂/ΣCH;
- диффузионная либо принудительная подача пробы; для принудительной подачи в руководстве указан расход 0,8 л/мин;
- цифровой дисплей 4 строки по 20 символов;
- регистрация результатов во внутренней энергонезависимой памяти;
- габаритные размеры не более 187 × 106 × 50 мм, масса не более 0,8 кг;
- IP20 либо IP54 по заказу;
- температура эксплуатации от −10 до +45 °C;
- автономная работа не менее 8 часов при температуре не ниже 0 °C;
- тип MONOLIT S внесён в Государственный реестр средств измерений РФ под № 82427-21.
