# План развития каталога, фильтров и документов

Статус: утверждено владельцем 25 августа 2026 года.

## Раздел документов

- основной адрес: `/docs`;
- ссылка «Документы» в header ведет непосредственно на `/docs`;
- документы автоматически собираются из опубликованных товарных JSON;
- единый поиск работает по названию документа, производителю, модели и названию прибора;
- дополнительные фильтры по типу документа, языку и категории не используются;
- поисковые URL закрываются от индексации, чистая страница `/docs` входит в sitemap;
- каждый документ связан с карточкой конкретного товара.

## Фильтры каталога

Первый этап использует только нормализованные данные:

- категория;
- текстовый поиск;
- множественный выбор контролируемых газов;
- множественный выбор производителя;
- наличие проверенной документации.

Выбранные параметры сохраняются в URL, показываются рядом с результатами и сбрасываются отдельно либо все сразу. На mobile панель перестраивается в один столбец.

## Следующий этап

Перед подключением назначения, диапазонов, принципа измерения, Ex/IP, каналов, интерфейсов и совместимости необходимо вынести эти значения из свободного текста в структурированные поля товарного контракта.
