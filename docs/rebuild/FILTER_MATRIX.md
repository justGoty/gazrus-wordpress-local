# Матрица фильтров каталога

Статус: рабочее предложение команды, не окончательное решение владельца. Обозначение P0 ниже означает рекомендуемый приоритет для MVP, который нужно подтвердить после инвентаризации реальных товаров и ответа на вопрос 16 в [OWNER_QUESTIONNAIRE.md](OWNER_QUESTIONNAIRE.md).

## Общие правила

- У каждой категории свой набор фильтров; нерелевантные поля не показываются.
- Состояние фильтров хранится в URL и восстанавливается кнопками браузера.
- Выбранные значения видны отдельными тегами и сбрасываются по одному или все сразу.
- Результат обновляется без скачков верстки и показывает количество найденных моделей.
- Параметры берутся только из структурированных полей товара.
- Случайные комбинации фильтров не индексируются как SEO-страницы.
- Общие фильтры наследуются всеми категориями и показываются один раз; таблицы категорий содержат только дополнительные параметры.
- P0 — предлагаемое обязательное наличие фильтра в MVP, P1 — доступность после наполнения данных. Окончательный статус утверждается владельцем.

Рабочие URL-ключи: `gas`, `brand`, `application`, `registry`, `verification`, `range`, `sensor`, `channels`, `sampling`, `ex`, `ip`, `interface`, `compatibility`. Списки значений сортируются и сериализуются единообразно, чтобы одинаковый набор условий не создавал разные URL.

## Поведение на mobile

- Кнопка «Фильтры» показывает количество выбранных параметров.
- Фильтры открываются в полноэкранной панели с закрепленными действиями «Показать» и «Сбросить».
- Сначала показаны три-четыре основных параметра категории; остальные находятся в разделе «Все фильтры».
- Результаты не прокручиваются в начало после каждого выбора.
- Диапазоны вводятся полями или степпером; длинные списки имеют поиск.

## Критерии приемки

- Пользователь может отфильтровать каталог по газу и ключевым техническим параметрам без текстового поиска.
- Невозможные комбинации не приводят к пустой странице без объяснения и способа сбросить ограничения.
- URL можно отправить коллеге и получить тот же набор результатов.
- Фильтры доступны с клавиатуры и имеют понятные подписи.
- Производительность проверена на фактическом объеме каталога.
