# Обновление изображений hero-слайдера

Дата: 16 августа 2026 года.

## Задача

- заменить мягкий общий фон hero-слайдера на три тематически разных изображения;
- сохранить светлую производственно-лабораторную концепцию с инженерными чертежами;
- подготовить отдельные версии для desktop и mobile;
- менять фон синхронно с активной категорией без геометрической анимации.

## Изображения

| Слайд | Desktop | Mobile |
| --- | --- | --- |
| Стационарные | `hero-stationary-scene-v2.webp`, 3200x1800 | `hero-stationary-scene-mobile-v2.webp`, 1440x1800 |
| Портативные | `hero-portable-scene-v2.webp`, 3200x1800 | `hero-portable-scene-mobile-v2.webp`, 1440x1800 |
| Сенсоры | `hero-sensors-scene-v2.webp`, 3200x1800 | `hero-sensors-scene-mobile-v2.webp`, 1440x1800 |

Изображения созданы встроенным ImageGen как отдельные фотореалистичные производственные сцены. После генерации выполнены кадрирование, качественное масштабирование, умеренное повышение резкости и экспорт в WebP.

## Правило hero-изображений

- у каждой категории должны быть собственные `heroImage` и `heroMobileImage`;
- desktop-версия: не менее 2560 пикселей по ширине, формат 16:9;
- mobile-версия: не менее 1200 пикселей по ширине, вертикальная композиция;
- слева сохраняется спокойная область под текст, предметный акцент располагается справа;
- на изображениях не используются логотипы, читаемые маркировки и неподтвержденные характеристики оборудования;
- переход выполняется только через opacity и отключается при `prefers-reduced-motion`.
