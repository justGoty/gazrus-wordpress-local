# Переработка Газоанализатор.рус

Статус: подготовительный пакет, черновик от 3 августа 2026 года.

## Главный вывод

Новая версия должна быть не презентацией компании и не обычным интернет-магазином, а инженерным B2B-каталогом. Посетитель должен быстро:

1. Найти прибор по модели, газу, задаче или условиям эксплуатации.
2. Отфильтровать ассортимент и выбрать технически подходящие варианты.
3. Получить документы и понять комплектацию.
4. Отправить содержательный запрос на КП или подбор.

WordPress сохраняется как работающий прототип и источник контента. Новую версию можно разрабатывать отдельно, без зависимости от WordPress.

Подтверждено владельцем: три основные категории, цены только по запросу КП, обязательные фильтры, формы на `info@prscom.ru`, трехцветная визуальная система и обязательный калькулятор газов. Сравнение и отдельная CMS отнесены к следующему этапу.

Правила совместной работы через Git и инструкция другому чат-боту: [COLLEAGUE_ONBOARDING.md](../../COLLEAGUE_ONBOARDING.md).

## Зафиксированные ограничения

- Не удалять текущую WordPress-версию до завершения переноса и проверки редиректов.
- Не публиковать пароли, дампы БД, резервные копии и приватные медиа.
- Не использовать выдуманные цены, наличие, дилерские статусы, сертификаты, отзывы или сроки.
- Не переносить текущий первый экран один в один.
- Не генерировать тысячи SEO-страниц из случайных комбинаций фильтров.
- Анимации принимать только после реальной проверки в браузере на desktop и mobile.
