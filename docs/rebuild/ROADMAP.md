# Roadmap переработки

Оценка 7–10 недель для двух разработчиков возможна только при готовых товарных данных и быстрых решениях владельца.

| Этап | Оценка | Результат | Definition of Done |
|---|---:|---|---|
| 0. Решения владельца | 1–2 дня | Утверждены модель продаж, ассортимент, KPI и дизайн | Заполнена анкета, сняты блокеры |
| 1. Инвентаризация | 3–5 дней | Товары, документы, изображения, URL и конкуренты | Есть единая таблица и список пробелов |
| 2. Структура и данные | 4–6 дней | Sitemap, URL, фильтры и модель товара | Утверждены IA и schema каталога |
| 3. UX и дизайн | 1–2 недели | Прототипы и дизайн основных страниц | Desktop/mobile и состояния утверждены |
| 4. Основа приложения | 1 неделя | Next.js, CMS, БД, роли, Docker и CI | Staging разворачивается из Git |
| 5. Каталог и страницы | 2–3 недели | Поиск, фильтры, товары, сравнение, документы | Все P0-сценарии работают |
| 6. Формы и calculator | 4–7 дней | КП, подбор, журнал заявок, проверенные расчеты | Доставка заявок и unit-тесты подтверждены |
| 7. Контент и SEO | 1–3 недели параллельно | Импорт, metadata, schema, redirects | 90% MVP-контента без критических пробелов |
| 8. QA и запуск | 4–7 дней | Проверка, backup, переключение и откат | Нет блокирующих дефектов |
| 9. Стабилизация | 7–14 дней | Ошибки, индексация и реальные воронки | Метрики и заявки наблюдаются |

## P0 — MVP

- Модель товара и импорт.
- Главная, каталог, категории и карточка.
- Поиск, фильтры и сравнение.
- Документы.
- Запрос КП и подбор.
- CMS.
- Проверенный калькулятор.
- SEO и редиректы.
- Метрика и события.
- Адаптивность, accessibility и browser QA.

## P1 — после запуска

- Избранное и сохраненный подбор.
- Умный мастер с рекомендациями.
- CRM и автоматическое формирование КП.
- Интеграция цен/остатков.
- Отраслевые страницы и кейсы.
- Календарь поверки.

## P2 — только при бизнес-необходимости

- Онлайн-оплата.
- Личный кабинет.
- 1С в реальном времени.
- Персонализация.

## Общий Definition of Done

- Реализованное поведение соответствует документированной модели.
- Нет служебного текста и выдуманных данных.
- Есть desktop/mobile проверка.
- Для анимаций есть визуальная запись или серия скриншотов ключевых состояний.
- Формы сохраняют контекст и доставляют заявку.
- Lighthouse/Core Web Vitals не имеют критических отклонений.
- SEO URL, canonical, schema и redirects проверены.
- Документация, WORKLOG и HANDOFF обновлены.
