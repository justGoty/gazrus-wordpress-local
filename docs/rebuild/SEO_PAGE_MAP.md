# Карта SEO-страниц

Статус: рабочая карта от 4 августа 2026 года. Канонические данные находятся в `web/content/seo/pages.json`; этот документ служит читаемым представлением и не заменяет JSON.

## Статусы

- `ready` — metadata и содержание готовы к индексации.
- `draft` — URL может быть реализован, но получает `noindex` и не входит в sitemap до выполнения условий.
- `planned` — маршрут и SEO подготовлены в данных, сама страница еще не реализована.
- `conditional` — решение об индексации принимается после проверки спроса, ассортимента, уникального содержания и внутренних ссылок.

## Динамические страницы

| Тип | URL | Индексация | Главный принцип |
|---|---|---|---|
| Товар | `/catalog/{category}/{slug}` | После статуса `published` и проверки фактов | Один canonical URL модели; `Product` без фиктивного `Offer` |
| Газ | `/gases/{gas}` | Условно | Спрос, устойчивый ассортимент или самостоятельный экспертный материал |
| Решение | `/solutions/{task}` | Условно | Реальная задача, экспертная схема выбора и связанные товары |
| Отрасль | `/industries/{industry}` | Условно | Самостоятельный спрос и отраслевое содержание без нормативных догадок |
| Бренд | `/brands/{brand}` | Условно | Проверенный бренд и содержательный ассортимент без ложного дилерского статуса |
| Материал | `/knowledge/{slug}` | После редакционной проверки | Автор или проверяющий, дата, источники и связи с каталогом |
| Фасет | `/catalog?{filters}` | `noindex` | Нормализованный URL, canonical на чистую страницу, отсутствует в sitemap |
| Модификация | `/catalog/{category}/{slug}?modification={id}` | `noindex` | Canonical базовой модели |
| Пагинация | `{listingPath}?page={number}` | Для существующих непустых страниц | Self-canonical и обычные HTML-ссылки |
| Внутренний поиск | `/search?query={query}` | `noindex` | Никогда не входит в sitemap |
| Preview, draft, thank-you, 404/410 | служебные URL | `noindex` | Реальный корректный HTTP-статус и отсутствие в sitemap |

Полные шаблоны находятся в `web/content/seo/templates.json`.

## Общие ограничения

1. Публичных цен, фильтра цены, корзины и онлайн-оплаты нет.
2. Запросы со словом «цена» получают честное объяснение факторов стоимости и CTA «Запросить КП».
3. `Product` без `Offer`, отзывов и рейтинга используется как семантическая разметка, а не как обещание товарного rich result.
4. Индексируются только полезные чистые URL с уникальным содержанием и ответом 200.
5. Страница не публикует «в наличии», «официальный дилер», «собственная поверка» и другие неподтвержденные утверждения.
6. Калькулятор индексируется только после проверки независимого расчетного ядра, справочника и видимых исходных условий.

## Robots и sitemap

- Рабочий файл: `web/public/robots.txt`.
- Карта сайта генерируется `web/src/app/sitemap.ts`.
- Фасетные, поисковые, preview, draft и thank-you URL исключены из обхода.
- CSS, JavaScript, изображения и документы товара не блокируются.
- Для Яндекса `Clean-param` применяется только к аналитическим и переходным меткам, не меняющим содержимое.
- `sitemap.xml` содержит только реализованные страницы со статусом `ready`, разрешенной индексацией и опубликованные товары.

## Расхождение со старой версией

Канонический URL товара новой версии — `/catalog/{category}/{slug}`. Старые `/product/{slug}/` не удаляются молча: после выгрузки фактических URL для каждого адреса создается прямой 301 в `web/content/catalog/redirects.json`. До инвентаризации автоматический общий редирект запрещен.
