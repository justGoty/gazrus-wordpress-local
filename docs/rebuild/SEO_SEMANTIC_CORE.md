# Семантическое ядро

Статус: предварительное ядро от 4 августа 2026 года. Машинный источник — `web/content/seo/semantic-core.json`.

## Важное ограничение

Частотность, сезонность и фактические позиции пока не проверены. Значения не моделируются и не заполняются оценками. Статус `not_validated` означает гипотезу на основе продукта, ассортимента и поискового намерения, а не подтвержденный спрос.

Перед массовым созданием страниц ядро проверяется в Яндекс Wordstat, Яндекс Вебмастере, Google Search Console и фактической выдаче. После проверки в JSON добавляются источник и дата, а не только число частотности в отдельной таблице.

## Кластеры P0

| Кластер | Целевая страница | Основные фразы | Правило |
|---|---|---|---|
| Общий коммерческий спрос | `/` | газоанализатор купить; газоанализаторы цена; промышленные газоанализаторы; поставка газоанализаторов | Цена раскрывается через комплектацию и КП |
| Общий каталог | `/catalog` | каталог газоанализаторов; виды газоанализаторов; газоанализаторы и сенсоры | Не конкурирует с тремя категориями по узким запросам |
| Стационарные | `/catalog/stationary` | стационарный газоанализатор; система контроля загазованности | Канальность, Ex/IP и интерфейсы остаются фильтрами |
| Портативные | `/catalog/portable` | портативный газоанализатор; переносной газоанализатор; многокомпонентный газоанализатор | Термины разводятся по реальному назначению моделей |
| Сенсоры | `/catalog/sensors` | сенсор для газоанализатора; замена сенсора; газовый сенсор | Главный коммерческий критерий — подтвержденная совместимость |
| Бренд и модель | товар | `{brand} {model}`; `газоанализатор {model}`; `{model} характеристики` | Одна модель — одна страница, без дублирующего суффикса сайта в данных |
| Подбор по газу | `/gases/{gas}` | `газоанализатор {gas}`; `газоанализатор {formula}`; `сенсор {gas}` | Страница создается только после проверки спроса и содержания |
| Поставка | `/services/supply` | поставка газоанализаторов; поставщик газоанализаторов; заказать газоанализатор | Условия и география должны быть подтверждены |
| Конвертер | `/calculators/gas-converter` | перевести ppm в мг/м³; ppm в проценты; калькулятор концентрации газа | Индексация только после проверки формул и справочника |

## Кластеры P1

| Кластер | Целевая страница | Примеры фраз | Условие запуска |
|---|---|---|---|
| Решения | `/solutions/{task}` | газоанализатор для котельной; для колодцев; для поиска утечек | Экспертно подтвержденный сценарий и товары |
| Отрасли | `/industries/{industry}` | для нефтегаза; химии; энергетики; водоканала | Самостоятельный спрос и отраслевой материал |
| Производители | `/brands/{brand}` | газоанализаторы `{brand}`; каталог `{brand}` | Проверенный бренд и достаточный ассортимент |
| Поверка | `/services/verification` | поверка газоанализаторов; поверить газоанализатор | Исполнитель, область аккредитации и порядок работ подтверждены |
| Калибровка | `/services/calibration` | калибровка газоанализаторов; калибровка сенсора | Услуга не смешивается с поверкой |
| Ремонт | `/services/repair` | ремонт газоанализаторов; замена сенсора; диагностика | Подтверждены исполнитель и поддерживаемые модели |
| База знаний | `/knowledge/{slug}` | как выбрать газоанализатор; принцип работы; единицы концентрации | Авторство, источники и дата проверки |

## Переменные шаблоны

- Товар: `{brand} {model}`, `{productType} {model}`, `{model} {gas}`.
- Газ: `газоанализатор {formula}`, `газоанализатор для {gasGenitive}`, `сенсор {gas}`.
- Задача: `газоанализатор для {taskGenitive}`, `контроль газа в {objectPrepositional}`.
- Отрасль: `газоанализаторы для {industryGenitive}`.
- Бренд: `газоанализаторы {brand}`, `{brand} {model}`.
- Калькулятор: `ppm {gas} в мг/м³`, `{sourceUnit} в {targetUnit}`.

Переменная не является командой автоматически создать страницу. Сначала проверяются спрос, ассортимент, уникальный ответ и риск каннибализации.

## Разведение интентов

- Главная отвечает на общий запрос о покупке, поставке и подборе.
- Каталог дает полный список и фильтры.
- Категория отвечает на тип оборудования.
- Газ отвечает на контролируемый компонент.
- Решение отвечает на задачу или объект.
- Отрасль отвечает на отраслевой контекст.
- Товар отвечает на бренд и модель.
- Материал отвечает на информационный вопрос и ведет к коммерческой странице только уместной ссылкой.

Один кластер назначается одной основной странице. Если новая страница претендует на существующий кластер, SEO-специалист выбирает объединение, уточнение интента или отказ от индексации.

## Чего не делать

- Не выводить фразы ядра в `meta keywords`: поисковые системы не используют это поле как рабочий сигнал.
- Не повторять точную ключевую фразу во всех заголовках и абзацах.
- Не создавать страницы по каждой комбинации газа, диапазона, IP, Ex, интерфейса и канальности.
- Не подменять «цена по запросу» числом `0`, минимальной выдуманной ценой или `Offer`.
- Не добавлять географические и дилерские модификаторы без реального присутствия и подтверждения.
