# Аудит текущей версии

Дата проверки: 3 августа 2026 года.

## Текущее состояние

- Локальная версия отвечает 200 по адресу http://localhost:8089/.
- Рабочая ветка master была чистой до создания этого пакета документов.
- Публичный домен разрешается в IP сервера, но HTTPS не завершает TLS-рукопожатие, а HTTP возвращает пустой ответ. Перед миграцией состояние нужно проверить повторно.
- WordPress-прототип сохраняется без удаления.

## Что можно переиспользовать

- Четыре главных направления.
- Сущности: товар, услуга, тип, газ, сенсор, канальность, бренд, исполнение.
- Тексты о подборе по техническим признакам.
- Старые URL, SEO-поля и структуру редиректов.
- Логотип и часть реальных изображений как исходные материалы.
- Калькулятор как прототип интерфейса и формул после проверки исходных данных.

## Подтвержденные проблемы

- Первый экран занимает почти весь viewport и содержит слишком много вложенных панелей.
- Текущий слайдер ранее давал визуальный рывок; его нельзя считать готовым без повторной browser-проверки.
- Один общий коллаж используется для разных типов приборов.
- В интерфейсе остаются служебные формулировки вроде «демо-карточка» и «для SEO».
- Каталог не имеет настоящего поиска по модели, производителю и артикулу.
- Фильтры представлены текстовыми полями и не формируют реальную выдачу.
- «Переносные» и «портативные» используются непоследовательно.
- Сенсоры заявлены, но полноценный раздел не сформирован.
- Выбранный товар и параметры подбора не передаются полностью в заявку.
- Нет сравнения, сохранения списка и загрузки ТЗ.
- Заявка зависит от одной почтовой отправки и не имеет журнала/повторных попыток.
- В коде не обнаружена полноценная схема событий аналитики.
- Калькулятор по адресу /calculator/ возвращает HTTP 200, но title содержит Page not found. Это подтвержденный soft 404.
- ПДК и НКПР зашиты в JavaScript без источника, версии и даты актуальности.

## Первые приоритеты

1. Подтвердить коммерческую модель и реальный ассортимент.
2. Создать нормализованную модель товара и таблицу импорта.
3. Утвердить структуру сайта и индексируемых страниц.
4. Выбрать дизайн-направление.
5. Создать новый проект отдельно от WordPress.
6. Исправить калькулятор только после проверки нормативных данных.
7. Подготовить полную карту старых URL до переключения домена.
