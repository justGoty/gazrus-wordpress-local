# UI guide

## Радиусы

- `8px` — кнопки, поля ввода, компактные переключатели и технические метки.
- `12px` — товарные карточки, фильтры и повторяющиеся информационные блоки.
- `16px` — крупные формы, галереи и самостоятельные медиаблоки.
- Полное скругление применяется только для круглых иконок и специальных индикаторов.

## Товарные карточки

- Изображение располагается на единой светлой товарной сцене без внутренней белой рамки.
- Карточка содержит название, краткое описание, подтвержденные характеристики и запрос КП.
- Технические метки должны быть понятны без расшифровки: например `1 канал`, `Ex`, `IP67`, `Локальная индикация`.
- Маркетинговые и служебные теги без полезной для выбора характеристики не добавляются.
- Фото и название ведут на страницу товара; кнопка запроса КП остается отдельным действием.

## Hero

- Фон светлый, производственное изображение остается различимым справа.
- Текст располагается на спокойной светлой подложке с достаточным контрастом.
- Категории переключаются нативными radio-контролами; клиентский код используется для стрелок и синхронизации состояния.
- Переход выполняется через мягкую смену прозрачности и небольшое масштабирование изображения.

## Страница товара

- Перечень применений выводится самостоятельными карточками, а не имитацией таблицы. Нечетное количество пунктов не создает пустую ячейку.
- Для многокомпонентных приборов формулы газов работают как доступный переключатель: выбранная формула раскрывает полное название и пояснение по комплектации сенсором.
- Блок «Как работает» показывает подтвержденный путь измерения от среды к сенсору, обработке и передаче сигнала.
- Химические формулы используются как рабочая навигация, а не как декоративный фон. Соединения и газы не называются химическими элементами.
- Микроанимации реагируют на наведение и фокус, не изменяют размеры сетки и отключаются системной настройкой сокращения движения.
